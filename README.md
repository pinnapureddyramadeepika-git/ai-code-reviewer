# AI Code Reviewer

An AI-powered web application that reviews source code, identifies bugs, detects syntax errors, and suggests improvements using Google Gemini.

## Features

- AI-powered code review
- Bug detection
- Syntax error identification
- Improvement suggestions
- Flask-based web interface

## Tech Stack

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- Git & GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/pinnapureddyramadeepika-git/AI-Code-Reviewer.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
